This release introduces the **Aurora Glass** UI redesign along with a comprehensive backend security and reliability hardening pass.

### Aurora Glass UI
- **Frosted glass design & 6 OKLCH palettes**: New default Aurora skin with Indigo, Ocean, Sage, Rose, Amber, and Slate palettes plus an independent glass toggle, all verified to WCAG AA contrast in light and dark modes.
- **Auto-collapsed process cards & right quick drawer**: Thinking and tool process cards automatically collapse on turn completion; swipe left on the chat view to open the right quick-panel drawer for model, permission, context, and theme controls.
- **Landscape split-pane & offline Share Card**: Refined tablet/landscape split layout and a zero-dependency Canvas 2D Share Card generator with native Android save and share.

### Backend Security & Reliability
- Hardened stream error handling, provider credential persistence and key cache cleanup, local LLM / OAuth shutdown cleanup, and pre-spawn abort races.
- Strengthened archive, ZIP/ZIP64, PDF, Office, Git safe.directory, hardlink, and concurrency boundaries across gateway modules.
- Switched app self-updates and feedback links to `WitchKlee/cccodroid` while retaining upstream prebuilt arm64 Devkit compatibility.
