This release **natively embeds the Magpie router & plugin gateway** inside cccodroid and resolves Android W^X execution restrictions on `targetSdk 36`.

### Native Magpie Gateway Embedding
- **Bundled as an APK native binary**: Ships official `yetone/magpie` (`v0.1.4848`, MIT) as `lib/arm64-v8a/libccmagpie.so` (DEFLATE-compressed to keep APK size compact), extracted by Android directly into the executable native library directory on both `targetSdk 36` and `targetSdk 28`.
- **W^X-safe trampoline for Bun & community plugins**: Extends `libccrun.so` so `MAGPIE_BUN` launches the on-demand Android arm64 Bun runtime (`v1.4.2`, SHA-256 verified) via `/system/bin/linker64`, enabling community plugins like WorkBuddy without `EACCES`.
- **Full UI & CLI integration**:
  - New **Built-in Magpie Gateway** card in Settings → Provider & Model with one-tap start/stop, auto-start toggle, live Bun engine installer, recent logs, and one-tap connect/model sync.
  - Opens Magpie's full Web Control Panel (`127.0.0.1:3430`) natively inside cccodroid with a per-boot random access key.
  - Added a live **Magpie Gateway** status tile to the right quick-panel drawer and a `magpie` wrapper command in the built-in terminal.
